This note serves as a quick guide into the XP table for Pathfinder sessions.

| Relative Level       | XP Gained |
| -------------------- | --------- |
| -5 (not allowed)     | ---       |
| -4                   | 63        |
| -3 (not recommended) | 94        |
| -2                   | 125       |
| -1                   | 188       |
| 0 (your level)       | 250       |
| +1                   | 375       |
| +2                   | 500       |
| +3 (not recommended) | 750       |
| +4                   | 1,000     |
| +5 (not allowed)     | ---       |
